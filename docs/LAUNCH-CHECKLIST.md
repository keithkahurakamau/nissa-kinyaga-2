## Credentials and reviews, supply these and they publish themselves

Everything below is wired and data-gated in `data/credentials.js`. Each entry
is `verified: false` and **renders nowhere** until you flip it, so the site is
correct as it stands. `test/credentials.test.js` fails the build if an entry is
marked verified while still carrying a placeholder reference, which is the
guard against a licence number being invented to fill a gap.

- [ ] **BRS registration number.** Client confirms Nissa Safaris is registered with the Business Registration Service but did not have the number to hand. Put it in the `brs` entry's `reference` and set `verified: true`.
- [ ] **Decide which operator credentials actually exist.** The client's answer selected both "none yet" and three licences, which cannot both be true. For each of `tra` (Tourism Regulatory Authority), `kato` (Kenya Association of Tour Operators) and `kws` (Kenya Wildlife Service), either supply the number and verify it, or delete the entry. **Note the distinction the entries encode:** the TRA licenses tour operators in Kenya; KWS manages parks and issues permits and does not license operators. The `kws` entry is worded accordingly and a test enforces it, so do not reword it to imply otherwise.
- [ ] **Review platform URLs.** Client says Tripadvisor and Google profiles exist but has not sent the links. Paste them into `reviewPlatforms` in `data/credentials.js`. A platform with `url: null` renders no badge at all, so no dead link can ship. Nothing was found for "Nissa Safaris" on Tripadvisor, Google or SafariBookings when searched, so confirm the profiles are live and public before adding them.
- [ ] **Real guest reviews.** `data/reviews.js` is deliberately empty and must stay that way until real guests send reviews through the form on `/reviews/`. Never seed it with samples: a fabricated testimonial is a false statement attributed to a named person. `AggregateRating` structured data is only emitted from real entries, and a test asserts none appears while the array is empty.
